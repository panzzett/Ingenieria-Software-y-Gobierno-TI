# 🏗️ Ingeniería del Software y Gobierno de TI

Memorias técnicas sobre **procesos de desarrollo, requisitos, arquitectura y patrones de diseño**, y sobre **gobierno de las TI con COBIT 5**.

> Trabajos académicos del Grado en Ingeniería Informática (asignaturas *Ingeniería del Software*, *Ingeniería del Software Avanzada* y *Servicios de Tecnologías de la Información*).

## 📄 Documentos

| # | Documento | Contenido |
|---|---|---|
| 1 | `01_modelo_de_proceso_agil_y_requisitos.pdf` | Plan para pasar de un modelo en **cascada a Scrum** en una empresa de software (diagnóstico, sensibilización, proyecto piloto y despliegue progresivo) y **diagrama UML de clases** de un sistema de reservas de biblioteca |
| 2 | `02_modelado_de_requisitos_trabajo_en_equipo.pdf` | Modelado de requisitos de un sistema de distribución de productos *(trabajo en equipo)* |

| 4 | `04_gobierno_TI_COBIT5_trabajo_en_equipo.pdf` | Aplicación del marco **COBIT 5** a un operador de infraestructura crítica (Red Eléctrica): procesos por área, acciones, métricas y mejora continua *(trabajo en equipo)* |
